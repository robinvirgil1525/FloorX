# Floor Manager - Smart Search Room Finder

**Floor Manager** is an intelligent, real-time room tracking and scheduling web application designed to help students and staff find available rooms in seconds using plain English searches, live maps, and predictive vacancy tracking.

You can view the live project here: [Smart Search Floor Manager](https://robinvirgil1525.github.io/FloorX/)

---

## Key Features

* **Natural Language Search:** Ask for what you need in plain English (e.g., *"I need an AC room on the ground floor for 2 hours"*), and the system automatically checks timetables to rank the best options.
* **Real-Time Floor Maps:** Interactive 3D and floor-by-floor maps tracking which rooms are **Available**, **Occupied**, or **Reserved Soon**.
* **Vacancy Prediction & Smart Recommendations:** Automatically ranks rooms that will stay vacant the longest based on weekly timetable data.
* **Room Timers:** Pick any room to see a live countdown to its next scheduled class.
* **Comprehensive Analytics:** View peak occupancy hours, most-used rooms, floor utilization metrics, and monthly usage calendars.
* **Custom Data Support:** Easily swap datasets using the JSON import feature.
